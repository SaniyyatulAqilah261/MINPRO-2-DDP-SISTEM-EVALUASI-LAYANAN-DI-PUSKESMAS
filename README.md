1. Deskripsi singkat program
   Fungsi Utama Program: Program ini dirancang berbasis teks (command-line interface) untuk mengelola dan mencatat data evaluasi kepuasan pasien terhadap layanan poli di puskesmas (seperti Poli Umum, Poli Gigi, dan Poli KIA).   Sistem Autentikasi (Login): Program menerapkan pembatasan hak akses (role-based access control) dengan dua jenis akun, yaitu Admin dan User (Pasien), yang dilengkapi penyembunyian karakter sandi menggunakan modul pwinput.   Fitur Menu Admin: Pengguna dengan hak akses admin dapat melihat seluruh data evaluasi (disajikan rapi menggunakan pustaka PrettyTable), menambah data baru, memperbarui (update) data yang sudah ada, serta menghapus data berdasarkan ID.   Fitur Menu User: Pengguna dengan hak akses user memiliki keterbatasan akses yang hanya dapat melihat daftar data evaluasi serta menambahkan data evaluasi baru ke dalam sistem.

3. Dokumentasi program & output
   - program
     Pada bagian awal program, terdapat impor pustaka eksternal seperti os untuk mengontrol fungsi sistem operasi (pembersihan layar), PrettyTable untuk menampilkan data dalam bentuk tabel yang rapi, serta pwinput untuk mengamankan proses input kata sandi. Struktur data utama dalam program ini menggunakan tipe data kamus (dictionary), yang terdiri dari variabel users untuk menyimpan kredensial akun beserta hak akses (role), dan variabel data_evaluasi untuk menampung data rekam jejak evaluasi pasien yang meliputi ID, nama pasien, pilihan layanan poli, serta nilai angka.
Alur eksekusi program dikendalikan oleh beberapa fungsi utama yang saling terhubung. Fungsi bersihkan_layar() bertugas membersihkan terminal agar antarmuka program terlihat bersih setiap kali terjadi pergantian menu. Fungsi tampilkan_data() bertugas mengecek apakah kamus data_evaluasi kosong atau berisi data, lalu menyusunnya menggunakan objek PrettyTable dengan kolom ID, Nama Pasien, Layanan Poli, dan Nilai Evaluasi. Selanjutnya, fungsi tambah_data() memungkinkan penambahan entri baru dengan meminta masukan nama, validasi pilihan poli (Poli Umum, Poli Gigi, atau Poli KIA), serta input nilai numerik antara 1 hingga 100 yang dilengkapi dengan pengecekan kesalahan menggunakan blok try-except agar program tidak crash apabila pengguna salah memasukkan tipe data.
Selain penambahan, program juga menyediakan fungsi ubah_data() dan hapus_data() untuk memodifikasi atau menghapus data yang sudah ada berdasarkan nomor ID yang dipilih. Fungsi ubah_data() memvalidasi keberadaan ID, mengizinkan perubahan nama, pembaruan poli, serta peninjauan ulang nilai evaluasi baru, sementara fungsi hapus_data() bertugas menghapus pasangan kunci-nilai dari kamus data_evaluasi jika ID ditemukan. Sistem keamanan login diatur melalui fungsi login() yang mencocokkan username dan password dengan data di kamus users, di mana jika valid, fungsi ini akan mengembalikan nama pengguna dan peran (role) mereka. Hak akses ini kemudian memisahkan alur navigasi ke dalam fungsi menu_admin() yang memiliki kontrol penuh atas penambahan, pengubahan, penghapusan, dan penampilan data, serta fungsi menu_user() yang memberikan akses terbatas hanya untuk menampilkan dan menambah data evaluasi saja. Seluruh siklus program ini dikoordinasikan di dalam fungsi utama main() yang berjalan secara terus-menerus menggunakan perulangan while True hingga pengguna memilih opsi keluar dari program.
